# プライバシーポリシー

最終更新日: 2025年2月13日

## はじめに

ONE QUEST（以下「本アプリ」）は、毎日1つのミッションをクリアするモバイルアプリです。本プライバシーポリシーは、本アプリにおける情報の取り扱いについて説明するものです。

## 収集する情報

本アプリが収集・保存する情報は以下のとおりです。

- **デバイス識別子（device_id）**: アプリ初回起動時にランダム生成されるUUID。氏名・メールアドレス・電話番号等の個人情報とは紐づきません。
- **ミッション履歴**: ミッションの内容・ステータス（達成/未達成）の記録
- **通知設定**: ローカル通知のON/OFF設定

本アプリは、氏名、メールアドレス、位置情報、連絡先、写真等の個人情報は一切収集しません。

## 情報の利用目的

収集した情報は、以下の目的にのみ利用します。

- 日替わりミッションの配信および進捗管理
- サービスの維持・改善

## 第三者への提供

本アプリは、収集した情報を第三者に提供しません。

ミッション生成にAI（OpenAI）を利用していますが、AIへのリクエストにユーザーのデバイス識別子やミッション履歴等のユーザーデータは含まれません。

## 外部サービスの利用

本アプリは以下の外部サービスを利用しています。いずれのサービスに対しても、ユーザー個人を特定する情報は送信しません。

| サービス | 用途 |
|----------|------|
| Vercel | APIサーバーのホスティング |
| Turso | データベース（ミッション履歴の保管） |
| OpenAI | ミッション内容のAI生成 |

## データの保管と安全性

- ミッション履歴はdevice_idと紐づけてサーバー上に保管されます
- すべての通信はSSL/TLSにより暗号化されています
- device_idはデバイス内のセキュアストレージに保存されます

## 通知について

本アプリはローカル通知のみを使用します。プッシュ通知サービス（FCM/APNs等）は利用していません。通知はアプリの設定画面またはOS設定からいつでもON/OFFを切り替えることができます。

## お子様のプライバシー

本アプリは13歳未満の児童から意図的に情報を収集することはありません。13歳未満のお子様が本アプリを利用していることが判明した場合は、該当する情報を速やかに削除いたします。

## プライバシーポリシーの変更

本プライバシーポリシーは、必要に応じて変更することがあります。変更があった場合は、本ページにて告知いたします。
